本地打印桥（PrintBridge.exe）使用说明
========================================

一、准备工作（一次性）
1. 云端登录 → 店铺管理 → 「本地打印桥」→ 复制「桥接密钥」。
2. 把 PrintBridge.exe 拷到店里连接标签机的电脑上（任意目录）。
3. 标签机已在该电脑安装驱动并测试可打印；记下打印机名称
   （不确定就先命令行运行：PrintBridge.exe list）。

云端地址怎么填（重要）：
- 经平台网关访问时，填「插件应用基础地址」，即浏览器地址栏里
  域名之后、页面文件之前的那段，例如：
    http://平台地址:端口/app/jewelry/t001
  （/app/jewelry 是应用路径，/t001 是租户路径，都不要漏）
- 直连插件独立端口时，填插件服务地址，例如：
    http://127.0.0.1:8002
- 两种都行；用平台地址时注意平台需已升级到支持 WebSocket 透传的版本。

二、首次运行
1. 双击 PrintBridge.exe，按提示依次输入：
   - 云端地址：如 https://你的域名
   - 桥接密钥：粘贴上面复制的密钥
   - 本机身份名：如 门店1#打印桥
   - 打印机名称：如 DASCOM DSL-735（留空 = 系统默认打印机）
   配置自动保存在 exe 同目录的 print_agent.json，之后双击直接运行。

2. 看到「已连接云端（WebSocket），身份：门店1#打印桥」即成功。

三、日常使用
- 只要这个窗口开着（可最小化），全店手机/电脑在系统里点「打印」，
  标签都会从这台电脑的标签机出纸。
- 建议加入开机自启：Win+R 输入 shell:startup → 把 exe 的快捷方式放进去。

四、常见问题
- 提示「打印桥不在线」：本程序未运行，或云端地址/密钥不对。
- 提示「打开打印机失败」：打印机名称不对，用 PrintBridge.exe list 查询后
  修改 print_agent.json 里的 printer 字段。
- 云端换了密钥（店铺管理里点过「重新生成」）：改 print_agent.json 里的 key。
- 云端为自签名 HTTPS 证书：把 print_agent.json 里 insecure_ssl 改为 true。

命令行参数：
  PrintBridge.exe list   列出本机打印机
  PrintBridge.exe run    启动桥接（双击默认即此）
