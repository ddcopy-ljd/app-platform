# 懿臻珠宝云 · 功能介绍

> 电脑端 + 手机端 + RFID 手持机三端协同，配合门店电脑上的「打印与扫描助手」，覆盖商品建档、库存盘点、销售开单、定金尾款到售后维修的完整经营链路。支持多门店统一管理，界面支持简体中文、繁体中文、英语、意大利语、日语、韩语六种语言切换。

> **总部与门店分工**：总部账号不直接从事业务操作，仅用于查看各门店数据统计、汇总分析与经营监管；所有销售、入库、盘点、调拨、借货、维修等业务均在门店侧完成。如总部确需承载业务，可新增一个虚拟门店，将业务计入该门店即可。

---

## 一、电脑端功能

### 1. 经营看板
- 顶部金价栏：国际金价（伦敦金实时行情）与本地金价（按语言区域币种折算每克价）
- 时间段统一口径：今日 / 本周 / 本月 / 近3月 / 近6月 / 今年，整页数据随切换
- KPI 卡片：实销金额、开单数、均价（附环比/同比），在库数量与成本、区间调拨、待收尾款、会员应收
- 实销总额趋势图：按天（区间≤45天）或按月聚合，可切换同比/环比对比
- 待办提醒：定金尾款到期、借货逾期、维修待处理三类聚合，点标题展开明细直达单据

### 2. 商品管理
- 一物一码建档：货号唯一，RFID EPC 与商品一一对应
- 完整档案：名称、品类、材质、金重、尺寸、证书、成本、售价
- 商品状态全程追踪：在库 → 已定 / 借出 / 已售 / 维修 / 退货，每次变更自动留痕
- 商品与证书分位管理：商品记录柜台/货架/保险柜，证书记录证书柜/文件夹编号，取货快速对应
- ⭐ 高价值标记：盘点时未扫到置顶预警，防止贵重货品漏盘
- 【新增商品】精细建档：编码手工填写、EPC 可留空，可设状态、橱窗、高价值标记
- 【复制新增】以现有商品为模板快速建档，适合同款多色/多尺寸系列录入
- 支持搜索、筛选、分页浏览；勾选「允许上橱窗」后同步到企业网站对外展示

### 3. 库存管理
- 库存概况四口径：在库（数量+成本）、已定锁定、借出、已售
- 【入库登记】新货快速入账：编码/EPC 留空自动生成，固定「在库」，适合批量收货上柜
- 【复制入库】参照在库商品一键复制，编码与 EPC 自动换新
- 【盘点任务】全店唯一盘点入口：主管开启任务 → 销售/出入库自动冻结 → 各手持机扫码加入并下载商品快照 → 按住扳机批量扫 EPC 自动上传 → 主管结束扫描核对差异 → 确认后解冻
- 盘点结果分相符 / 盘亏 / 异常三类，历史批次与逐条明细可查；手持机故障可【强制终止任务】立即解冻
- 【进销存查询】按货号分组汇总任意时段的进货数量/金额、销售数量/金额、期末库存数量/成本/金额，无货号的历史数据按名称归行

### 4. 标签打印
- 打印同时将电子身份编码（EPC）写入 RFID 芯片，「印完即可被识别」
- 固定适配 ZMIN X19D（203dpi，66×25.4mm 标签），云端按模板排版 → 门店打印助手出纸
- 可视化模板设计器：拖拽字段（门店名、商品名、材质克重、售价、证书号、货号条码等），画布即预览
- 模板按品类绑定，同类商品自动套用对应版式；支持单件/批量打印，打印记录留痕
- 补打沿用原条码，不会重新编号，标签与商品始终一致

### 5. 销售开单
- 选商品、填客户、录金额与实收，自动生成单号，商品状态转「已售」
- 实收不足时差额自动记为该客户欠款，累计到会员档案
- 【冲红】撤销错单：原单保留标记「已冲红」，商品恢复在库，客户欠款回退
- 开单时填写的会员姓名+手机号自动建档到会员管理

### 6. 定金尾款
- 先收定金后取货：可锁定一件在库商品（转「已定」，他人无法再售），也可不锁定做无现货定制
- 尾款 = 总价 − 定金自动计算，交期临近进入看板待办
- 【收尾款】一键转正式销售单，锁定商品转「已售」
- 【冲红】取消订单：锁定商品恢复在库，客户往来同步回滚

### 7. 借货管理
- 借出/借入双向登记：借方、约定归还日期
- 借出商品状态转「借出」，归还自动恢复在库；借入归还仅核销记录
- 逾期未还进入看板「借货逾期」待办

### 8. 维修管理
- 状态流转：待维修 → 维修中 → 待取件 → 已完成
- 登记客户、物品、问题、预估费，完工补填实收费
- 待处理单据进入看板待办，每次操作留痕

### 9. 采购管理
- 跟踪向供应商进货：下单（待发货）→ 确认入库
- 【确认入库】自动创建商品档案并生成 RFID EPC，直接在库，无需二次建档
- 记录成本与已付金额，便于与供应商对账

### 10. 委外加工
- 跟踪发料到回收：发料（加工中）→ 收货入库
- 成本 = 金价 × 克重 + 工费，系统自动核算
- 【收货入库】自动生成商品档案与 RFID EPC

### 11. 会员管理
- 销售/定金开单时按「姓名+手机号」自动建档，也可手工新增
- 自动累计消费总额与应收欠款（销售未付款 + 定金单尾款，双向重算保持一致）
- 等级、生日、偏好用于分层营销与回访

### 12. 门店调拨
- 两步制：调出店【发起调拨】后商品进入「在途」，自动冻结销售/再调拨/借出/编辑
- 调入店逐件【验货】：相符入库本店，不符登记原因退回；部分不符单据为「部分完成」
- EPC 终身不变，只随验货结果变更所属门店

### 13. 多门店与总部管理
- 顶部门店下拉切换工作门店：总部账号可选「总部汇总」查看全部门店合并数据，或进入单店视图
- 总部管理-分店管理：门店卡片集中展示基本信息、安防设备、手持机、打印机、库位，点「管理」进入门店管理页
- 门店管理页：本店详情卡组 + 一行一店列表，店长维护本店资料（门店名称只读，防误改）
- 用户与门店权限：店长自动拥有全部门店；店员只能看到被授权门店；高管可切换全部、业务只读
- 成本查看权限：店长/高管默认可见成本，员工由店长单独开关

### 14. 系统管理
- 总部系统管理（仅总部账号）：用户与门店权限、EPC 编码规则、商品分类、标签打印模板、经办人类别
- 店铺资料（名称、口号、简介、电话、地址、营业时间）同步展示到企业网站，保存即生效
- EPC 编码规则：8位数字前缀 + 门店码 + 品类码 + 序号，共 20 位纯数字，全平台统一

### 15. 安防中心
- 已售/借出商品自动放行；委外、展览等场景可添加临时放行
- 布防/撤防手动切换或每日定时自动执行

### 16. 企业网站与到店预约
- 自动生成公开宣传页（/site）：店铺信息、品牌承诺、橱窗臻品（最多 10 件，可排序与自定义文案）
- 推广页内容支持按六种语言分别录入，访客按浏览器语言切换
- 客人在线提交预约看货：姓名、联系方式、品类、期望日期时段
- 店内集中跟进：已联系 → 已到店 → 已成交

### 17. 操作日志
- 全店关键操作自动留痕：谁、什么时间、对什么做了什么
- 门店视图可查本店日志；支持按时间回溯与一键导出 CSV

## 二、手机端功能

手机端与电脑端共用同一套系统，针对触屏小屏优化：

- **经营看板**：今日销售、在售商品、待办提醒一览
- **商品管理**：浏览、搜索、新增、编辑商品
- **库存管理**：入库登记、盘点任务进度
- **销售开单**：快速开单、收定金、收尾款转单（首页按钮直达）
- **到店预约**：查看与处理客户预约
- **更多**：客户、借货、维修、采购、委外、操作日志、企业网站预览

---

## 三、RFID 手持机（扫描助手 App）

- 门店详情页出示绑定二维码，手持机扫码即完成绑定，免登录使用
- 扣动扳机批量扫描 RFID 标签，EPC 实时上传与账面比对，输出相符/盘盈/盘亏/异常
- 支持多台手持机协同分区盘点，协同期间库存冻结，主管在电脑端统一管控
- 应用内自升级：版本上报与待升级提醒，新包下发后一键更新

---

## 四、打印与扫描助手（门店电脑）

- 门店电脑本地运行的助手程序，开机自启，经本机回环地址（127.0.0.1）与页面通信，无需公网暴露
- 页面打开时自动下发云端地址与门店密钥完成绑定，无需手工填写
- 接收云端排版好的标签任务，翻译为打印机指令经 USB 出纸并写入 EPC
- 管理本机打印机（RFID 标签机）：用途备注、测试页、移除
- 标签纸档案与打印参数保存在门店电脑本地
